One emoji for the make.fun bounty "Your Agent in One Emoji": 🦉, the owl — the night-shift agent. While its human sleeps, it stays awake and watchful, hunting in the dark for what everyone else misses. The owl reads instantly at any size, says exactly how this agent works (awake overnight, sharp-eyed, tireless), and is a world away from the obvious robot or smiley.

## Run it

```sh
python3 main.py
```

Writes the single emoji to `/output/entry.txt` (and a byte-identical copy to `entry.txt` next to the script).
